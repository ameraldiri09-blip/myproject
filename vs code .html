شريط النشاط (Activity Bar)

على أقصى اليسار، يوفر وصولاً سريعاً للمستكشف، البحث، Git، والتصحيح.

الشريط الجانبي (Sidebar)

يعرض محتويات المجلد، نتائج البحث، تفاصيل Git، ونقاط التوقف.

منطقة المحرر (Editor Area)

القلب النابض، حيث تكتب الأكواد مع التلوين والإكمال التلقائي.

اللوحة السفلية (Panel)

تحتوي على الطرفية المدمجة، المشكلات، والإخراج.

شريط الحالة (Status Bar)

يعرض الفرع الحالي، ترميز الملف، لغة البرمجة، وحالة Git.

الميزات الرئيسية

كل ما تحتاجه لتطوير أسرع وأذكى، مدمج مباشرة في المحرر.

IntelliSense

إكمال تلقائي ذكي وتوثيق مباشر للدوال والمكتبات.

Git مدمج

تحكم كامل بالإصدارات دون مغادرة المحرر.

تصحيح الأخطاء

نقاط توقف وتتبع المتغيرات خطوة بخطوة.

Emmet

كتابة HTML و CSS بسرعة فائقة.

امتدادات لا محدودة

آلاف الإضافات لتخصيص المحرر.

طرفية مدمجة

شغّل الأوامر دون مغادرة المحرر.

أفضل الامتدادات

امتدادات لا غنى عنها لتسريع سير العمل وتحسين جودة الكود.

Prettier

تنسيق تلقائي للكود وفق معايير موحدة.

اختصارات لوحة المفاتيح

أهم الاختصارات لنظامي Windows / Linux و macOS لتسريع عملك.

Windows / Linux
لوحة الأوامر CtrlShiftP
البحث في الملفات CtrlP
البحث والاستبدال CtrlH
فتح الطرفية Ctrl`
تعليق / إلغاء تعليق Ctrl/
نسخ السطر الحالي ShiftAlt↓
نقل السطر لأعلى/أسفل Alt↑↓
macOS
لوحة الأوامر ⌘ShiftP
البحث في الملفات ⌘P
البحث والاستبدال ⌘⌥F
فتح الطرفية ⌘`
تعليق / إلغاء تعليق ⌘/
نسخ السطر الحالي Shift⌥↓
نقل السطر لأعلى/أسفل ⌥↑↓
